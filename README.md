# GeoJSON Polygon Editor

Geojson.io mantığında poligon düzenleme uygulaması.

Çalışan harita ve arayüz: [gamze-harita-arayuz](https://github.com/GamzeCanpolat/GeoJSON-Polygon-Editor/tree/gamze-harita-arayuz).

- Gamze: harita, poligon düzenleme, JSON/Tablo, Excel/GeoJSON içe aktarma ve arayüz.
- İkinci geliştirici: sunucu, kalıcı proje kaydı, veri servisleri ve topolojik doğrulama.

Kurulum, entegrasyon sözleşmesi ve ayrıntılı iş bölümü geliştirme dalındaki README ve docs klasöründedir. main ortak başlangıç dalıdır; geliştirmeler inceleme sonrasında buraya birleştirilir.
